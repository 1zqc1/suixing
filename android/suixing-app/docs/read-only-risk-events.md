# 只读风险事件接口草案

此文档供队长、队友 A 与 Android 端商定数据格式。B1/B2 仅支持手机 GPS 和明确标记的模拟路线。目前没有车辆连接、事件传输或风险告警数据。以下字段是未来适配器建议，需待车端协议确认后映射。

| 字段 | 约定 |
| --- | --- |
| 设备标识、车端会话标识、车端事件序号 | 原样保留。三者共同标识一条输入，用于处理重发、乱序和中断。设备重启后的序号复用需由车端会话边界区分。 |
| 事件类型、级别、原始载荷与协议版本 | 仅展示协议已定义的含义。未知值保留原值，界面可显示“未知”。 |
| 原始车端时间戳、单位、时钟域 | 保留生产设备给出的原值，并明确单调时钟或 UTC、起点与精度。缺失字段保持为空。 |
| 手机接收时的 elapsedRealtime 毫秒、UTC 毫秒 | 在接收端分别采集，供同一手机开机周期内排序及跨日志粗略检索。手机重启后须另起接收时间域。 |
| 可选的手机记录会话引用 | 只表示接收时所在的本机会话。位置匹配应单独保存匹配依据和不确定性。 |

手机与车辆的单调时钟各有起点，不能直接相减或据此定位到同一轨迹点。手机接收时刻包含传输与排队延迟，不能代替车端事件发生时刻。时间同步方式、误差界限、协议版本、传输格式及断流处理均待双方确认。

适配器面向读取、留存与展示。接口不包含速度、转向、急停或其他车辆指令，未收到事件时保持“无数据”。
