# 随行 V4 两驱高位感知概念装配

左右两只普通橡胶轮各由一台减速电机驱动，前部两只被动脚轮支撑车身。使用者推行，车体按操作者已表达的转向意图提供有限差速助力，危险时请求制动并触发双侧握把振动。

| 项目 | CAD 名义值或布局 |
|---|---|
| 底盘含轮外廓 | 长 450 × 宽 350 mm |
| 整机外廓含后伸握把与急停 | 长 632 × 宽 350 × 高 979 mm |
| 轮组 | 左右驱动轮直径 180 mm、宽 30 mm，驱动轮中心距 320 mm。前脚轮直径 84 mm，脚轮回转轴至驱动轴纵向距离 244 mm |
| 前置双目 | 镜头中心离地 600 mm，基线 60 mm。模型的安装方向按前视水平基准，俯角和支架孔位待装车标定 |
| COIN-D6 | 驱动轮前方的立柱顶端，安装面 628.1 mm，名义扫描平面 655 mm |
| 手柄 | 握持中心离地 950 mm，试装时检查 850–1050 mm 握持范围。两侧握把振动，横梁设本地确认与急停 |
| 机内布置 | 电池位于底板中部，飞腾派放在可访问的上层托板，两路驱动靠近驱动轮 |

前置立柱固定到底板，穿过可拆外罩。双目与 D6 共用前置立柱，两个安装面各自设载体。相机前置有利于保留前视视野，雷达的扫描面高于双目外壳。以车头为 0°，本模型估算两根扶手立柱各遮挡一段后向扫描，约为 −170° 至 −165°、165° 至 170°。实际角度应结合立柱、操作者、线束、装配误差和装车扫描验证。将遮挡视为未知区域。高位雷达对低于扫描平面的障碍物、台阶边沿及落差可能缺少有效观测，双目的有效覆盖以实测为准。

本模型采用候选轮径、轮距和装配包络。尚需用实物确认轮胎、电机与脚轮的接口和载荷、底盘与立柱连接刚度、带扶手载荷的前后及侧向稳定性、双目实际型号及下方盲区，并在受控场地验证无助力推行阻力、脚轮转向、制动距离和握把受力。整机握把已建为 950 mm 的静态位置，伸缩、调节锁止和防夹结构待细化。

握把中心在驱动轴后方 294 mm。扶手下压会绕驱动轮接地线产生后倾力矩。试装需测量实际质量、重心和握把载荷，并验证突然下压、急停与坡面上的稳定性，再确定驱动轴位置和是否需要后部防倾支撑。

## 模型和验证

- [整车 STEP](Suixing-V4-TwoDrive-HighSensors.step)包含 41 个独立命名的组件。
- [轴测和侧视预览](V4-layout.png)由同一套 CAD 几何生成。
- [几何检查](candidate-geometry.json)记录静态体积干涉、脚轮回转包络、两段后向遮挡和 STEP 回读结果。
- 源模型由 [build_two_drive_rover.py](../build_two_drive_rover.py) 生成，尺寸以毫米计，CAD 坐标 +Y 朝上、+Z 朝前。
- [辅助出行原型](../assist/README.md)可运行抽象动作回放。V4 实车需重新测定转弯扫掠包络、时效阈值和制动参数。

在 Windows x64 安装 Python 3.10，随后从仓库根目录运行。重建会更新同目录的 STEP、零件 STEP 和几何 JSON。用于核对归档时，在临时工作副本执行，STEP 文件头的生成时间会变化。

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install cadquery-ocp-novtk==7.9.3.1.1
.\.venv\Scripts\python.exe docs/rover-v1-20261116/build_two_drive_rover.py
```

复验检查 `step_reloaded_components=41`、`step_reloaded_valid=true`，以及静态干涉与脚轮扫掠数组均为空。概念装配可直接从 STEP 导入支持该格式的 CAD。
