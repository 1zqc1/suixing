# 随行辅助出行软件实施计划

以 V3 装配与交接记录为型号基线。在独立的 `assist` 软件目录建立场景回放入口。对照瓶盖质检项目的公共协议和 OpenAMP 证据，沿用“消息有效期、业务确认、执行回读”的设计原则。现有传感器和其他项目的运行代码保持原状。

1. 先建立行为测试。覆盖横切、平行通过、单源报警、感知失效、方向确认、停车锁存和监护端隔离。
2. 将代码拆为数据契约、环境融合、运动许可和 JSON 回放四层。回放只生成意图和状态，不连接电机。
3. 增加可重复的横切回放与架构说明。逐图记录采纳内容、接入责任、待确认型号和上板证据。
4. 执行本机测试与命令行回放，核对控制与监护输出。实机驱动、实时核、执行器和故障注入由台架验证确认。
