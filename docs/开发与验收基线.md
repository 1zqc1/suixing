## 复验入口

- **ROS 2 Humble**。从仓库根目录运行 `bash dev-env/verify-humble.sh`。需要 Ubuntu 22.04 的 Humble、colcon、rosdep 和 OpenCV 开发包。
- **飞腾**。将指定版本的 SDK 放在 `~/work/phytium-free-rtos-sdk`，将配套 standalone 放在 SDK 的 `standalone/`，将裸机编译器放在 `~/opt/arm-gcc`。运行 `bash dev-env/build-phytium-openamp.sh`，产物及 ELF 核验记录位于 `dev-env/phytium-build/`。
- **YOLOv8n**。使用 Windows x64 的 Python 3.11 和 `dev-env/yolo-baseline/requirements-win-cu128.txt`，把官方 `yolov8n.pt` 放入 `dev-env/yolo-baseline/`，再运行 `python dev-env/tests/verify-yolo.py`。脚本会验证权重 SHA-256。[官方模型权重](https://github.com/ultralytics/assets/releases/download/v8.3.0/yolov8n.pt)
- **ESP-SR**。在启用 ESP-IDF 5.4.4 的终端进入 `dev-env/tests/esp-sr-baseline/`，运行 `idf.py -D IDF_TARGET=esp32s3 build`，随后运行 `python verify-artifacts.py`。
- **Android**。设置 JDK 17 与 SDK API 36、Build Tools 35.0.0。在 `dev-env/tests/android-baseline/` 运行 `.\gradlew.bat assembleDebug`。

ESP-SR 的真实音频识别、Android 手机运行、随行传感器与 STM32 整机闭环，以及 Hailo HEF 编译与板端运行，均待对应实物或工具包验收。
